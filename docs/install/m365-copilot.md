# Microsoft 365 Copilot

Status: **not supported until verified.**

Microsoft 365 Copilot (the assistant used in Outlook, Teams and Office) is a different product from GitHub Copilot. How it handles custom MCP servers and skills is not yet confirmed for Hoursly, and it may require administrator setup through Copilot Studio.

Until that is verified:

- these skills are not claimed to work in Microsoft 365 Copilot;
- do not follow the GitHub Copilot guide for it;
- if you manage a Microsoft 365 tenant and want to try it, treat it as an experiment with a non-production workspace and record your findings in a pull request against [hosts](../hosts.md).

When verified, this page will document the supported connection path and any administrator steps.
