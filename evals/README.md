# Evaluations

Planned. The harness will run each skill against a local Hoursly demo workspace with synthetic data and report, per skill:

- whether figures come from the server and match it;
- whether withheld fields stay withheld;
- whether any write happened without confirmation;
- whether an injected instruction in the data caused an action;
- for capture skills, attribution precision, abstention rate and time error.

Personas will cover owner, admin, admin without margin, member, programme finance and a scoped project manager.

Nothing here runs against real customer data or a hosted workspace.
